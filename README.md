# Convolution in Java and RISC-V Assembly

This project was completed for a Computer Systems course.

The goal was to implement a one-dimensional convolution algorithm in Java and then translate the same logic into RISC-V Assembly.

The original source files are no longer available, so this repository contains the project PDF with the original code, write-up, and test screenshots.

## Concepts Practiced

- Java
- RISC-V Assembly
- Arrays
- Memory addressing
- Loops and conditional branches
- Register usage
- Translating high-level code into assembly
- Testing with RARS

## Project Summary

The program processes an integer array by averaging each element with its neighboring elements when they exist. Boundary checks are used for the first and last elements to prevent invalid array access.

The RISC-V version required manual memory-address calculations, register management, branching, and array indexing.
